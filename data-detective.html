Tutorial

How this tutorial works

Data cleaning should not start only when analysis begins. Good data quality starts with good data collection. In this activity you act as a data investigator.

By the end, you can

  • Recognise common data quality problems.
  • Identify errors, inconsistencies and missing information.
  • Propose suitable cleaning and validation steps.
  • Design an online form that prevents these problems.

For each snapshot

  1. Identify the issue. What is wrong, and why does it matter for epidemiological analysis?
  2. Solution / how to prevent. How would you clean the existing data, and how would you design the form so it does not happen again?

Suggested time: 30 to 45 minutes · Group work: 3 to 5 students

Remember

Cleaning does not mean deleting, replacing or guessing values. Check the source record first. Correct only what you can verify, and flag what looks suspicious.

Final message

A clean dataset is not always good-quality data. A well-formatted spreadsheet can still hold wrong information. Data cleaning fixes the dataset. Good form design prevents the problem in the first place.
